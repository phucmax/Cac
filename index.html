Công cụ nhanh

Chọn một đoạn code trong editor rồi mở công cụ để xóa hoặc thay thế chính xác đoạn đó.

⌘
Sửa code trực tiếpGõ, dán và chỉnh file Lua ngay trong trình duyệt.
⌁
Tìm đoạn codeDán đoạn cần tìm, kể cả nhiều dòng và khoảng trắng.
↔
Thay thế hàng loạtXóa hoặc thay tất cả kết quả chỉ với một nút.
Mẹo: Bôi đen đoạn code trong editor trước khi bấm nút. Ô “Đoạn cần tìm” sẽ tự điền sẵn nội dung đang chọn.
